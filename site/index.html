Nine enforcement domains

01

Behavioral Contracts

Every agent declares what it's allowed to do — tools, models, destinations, actions. A 31-stage decision chain enforces those declarations before every request reaches the LLM.

02

Evidence Grounding

Destructive actions blocked without prerequisite verification. An agent can't issue a refund without looking up the order. Can't sign off tapeout without running DRC. Enforced at the proxy.

Learn more →

03

Credential Indirection

Agents never hold real API keys. Virtual keys with AES-256-GCM encryption. Instant per-agent revocation. Per-key budget limits and model scoping.

Learn more →

04

Graduated Response

Not binary allow/deny. Five escalation levels from monitoring to quarantine. Asymmetric de-escalation prevents oscillation. Behavioral fingerprinting detects unknown agents.

Learn more →

05

Bidirectional Content Governance

Scans both inbound requests and outbound responses. Six detection layers fused with Dempster-Shafer evidence theory. 275+ RE2 patterns. No ML. Response-side scanning catches injection that succeeded — not just attempts, but actual compromises in LLM output.

Learn more →

06

Infrastructure Enforcement

Kernel-level iptables/nftables/cilium rules capture all traffic. Applications cannot bypass the proxy. Four enforcement backends for any Kubernetes distribution.

Learn more →

07

Streaming Scanning

Per-SSE-event classification with 8KB sliding window. Mid-stream cancellation injects provider-native errors. PII in event 47 of a stream? Cancelled at event 47.

Learn more →

08

Tamper-Evident Forensics

SHA-256 hash chain where every decision is cryptographically linked to the previous one. Insertion, deletion, and reordering are all detectable. Not logging — proof.

09

SCIM 2.0 provisioning. SAML and OIDC SSO. SPIFFE JWT-SVID for zero-trust service identity. Four-role RBAC. Agents get real identity infrastructure.
