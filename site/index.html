Your coding agent says the tests passed. What actually ran?

Rashomon keeps a local record of Claude Code’s tool calls, failed commands and subagent activity. It flags failures the agent’s final summary leaves out.

How it works

Record. Compare. Inspect.

  1. 01

    Record

    Hooks record each step Claude Code takes, its subagents’ included, and whether it worked, in a folder on your machine.

  2. 02

    Compare

    At the end of a turn, recorded failures are checked against the agent’s final message. When something is off, one line says so.

  3. 03

    Inspect

    rashomon report shows the full record: subagent calls, failed steps, test runs, and what Rashomon could not see.

  • Not a sandbox. It never stops or contains the agent.
  • Not exhaustive claim checking. It looks for 43 failure words in the summary and lists the ones that are absent.
  • Claude Code only today, on macOS and Linux. Open-source alpha.

Get started

Install it as a Claude Code plugin.

$ claude plugin marketplace add altrace-dev-role/rashomon
$ claude plugin install rashomon@rashomon
$ claude plugin enable rashomon@rashomon

Start a new Claude Code session, then run /rashomon:report. The README also covers a command-line install.
